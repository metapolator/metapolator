# Upstream (JS) bugs found during the port

The port reproduces these on purpose, because the goldens depend on them.
Fixing them is a separate step, done behind tests once the port is complete.

| #   | where                                              | bug                                                                                                                                                                                                  | effect                                                                                           |
|-----|----------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------|
| 1   | Atem-MOM `Project.exportUFOInstance`               | passes `formatVersion` twice to `_getUFOExporter`                                                                                                                                                    | `precision` is ignored; coordinates round to 3 decimals (the format version)                     |
| 2   | Atem-MOM `Project.getOTFInstance`                  | calls `otfExporter.do_export` (does not exist)                                                                                                                                                       | the sync OTF API always fails; the UI used `getOTFExportGenerator`                               |
| 3   | Atem-MOM `MasterGlyphSet.get`                      | never returns its result                                                                                                                                                                             | components are not drawn in OTF output                                                           |
| 4   | Atem-MOM `OTFExporter`                             | passes the `unicodes` *array* as opentype.js `unicode`                                                                                                                                               | cmap and OS/2 coerce arrays: `[]` → 0, `[n]` → n, longer → NaN → 0; `usDefaultChar` is always 32 |
| 5   | opentype.js 0.6.3                                  | `advanceWidth` must be truthy                                                                                                                                                                        | OTF export fails for a font with any zero-width glyph (e.g. sean_hairline)                       |
| 6   | Atem-MOM `UFOImporter._getSourceGlyphClasses`      | calls `readGroups(true)` (async), stores a Promise                                                                                                                                                   | groups of the imported UFO never become glyph classes                                            |
| 7   | Atem-MOM `ImportOutlinePen._flushContour`          | `movePt = [0]` instead of the point                                                                                                                                                                  | open contours start at (0, 0) (they are skipped by default anyway)                               |
| 8   | Atem-MOM `import/ufo/tools.getDirection`           | `!firstRound \|\| !lastRound` is always true                                                                                                                                                         | direction search always tries all three points                                                   |
| 9   | Atem-Math-Tools `hobby.control2tensionIn/Out`      | passes `p1` as `z0` and a magnitude as `dir1`                                                                                                                                                        | wrong tensions (unused by the shipped CPS)                                                       |
| 10  | Atem-Property-Language `Transformation` operator   | passes six numbers to a constructor taking one array                                                                                                                                                 | always the identity                                                                              |
| 11  | metapolation CPS + `primary.cps`                   | `primary.cps` puts `contour > p` in `@namespace("glyph")` (specificity 0,0,3), the metapolation template's `contour > p` (0,0,2) loses; its `inTension` needs `inLength`, which instances don't have | instances of fonts with plain contours fail to export (tests/golden-workflow: `instance-0`)      |
| 12  | Atem-MOM UI `instanceTools` / `addMasterToSession` | the UI passes master *nodes* to `addMasterToSession`, which expects names                                                                                                                            | `project.save()` throws (js-yaml can't dump the node)                                            |
| 13  | gonzales tokenizer                                 | `urlMode`/`blockMode` are module globals that leak between parses                                                                                                                                    | not reproduced: the port resets them per parse                                                   |
| 14  | gonzales + Atem-CPS                                | one unsupported character, unknown at-rule or invalid selector fails the whole file                                                                                                                  | `^` (pow) can never be used in a CPS file (crates/mp-cps/tests/README.md)                        |
